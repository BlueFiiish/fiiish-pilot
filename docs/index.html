Fiiish Pilot

A free, ban-safe on-screen minimap and navigation overlay for Escape from Tarkov.

Fiiish Pilot shows your live position, extract and quest directions, and your squad's positions right on top of the game, updating every time you take a screenshot. It's built for friends playing Tarkov together and sharing one map.

Ban-safe by design. Fiiish Pilot never reads game memory, never injects into the game process, and never sends input to the game. It only watches the Screenshots folder Tarkov itself writes to and reads Tarkov's own log files — the same passive technique tools like TarkovMonitor have used for years. Your dot only moves when you press your screenshot key.

Download

Download Setup.exe All releases / Portable version

Setup.exe is a normal one-click installer — installs for your user only, no admin needed, adds a Start Menu shortcut. That's what almost everyone wants. The Portable exe on the releases page needs no install at all if you'd rather run it from a folder or USB stick.

Install

  1. Run the downloaded exe.
  2. Windows will show a blue "Windows protected your PC" SmartScreen screen. This happens because the app isn't signed with a paid code-signing certificate — it does not mean anything is wrong. Click More info, then click Run anyway.
  3. The app launches into your system tray (bottom-right of the taskbar, near the clock) and opens a first-run setup wizard.
Don't see the wizard or the SmartScreen prompt? Check the hidden-icons arrow in your taskbar tray — the app runs quietly in the background once it's set up.

The setup wizard

The wizard does the annoying parts for you and only asks you to confirm or choose:

  • Auto-detect. It finds your Tarkov Screenshots folder and Logs folder on its own (common if OneDrive redirects your Documents folder, it'll catch that too) and tells you if something looks wrong.
  • Your keys. Every hotkey in the app is yours to set — click a key in the wizard and press whatever you actually want to use. It warns you live if two actions clash, if something else on your PC already grabbed that key, or if Tarkov itself needs it.
  • Live screenshot test. Take a screenshot in-game with the key you just set, and this step turns green the instant the wizard sees it — confirming the whole pipeline works before you ever load into a raid.
  • Squad (optional, see below).

You can reopen the wizard any time from the tray icon if you want to change anything later.

Two settings inside Tarkov

1Settings → Game → Screen mode: Borderless. The overlay can't draw on top of exclusive fullscreen. Borderless has no real performance cost on a modern PC.

2Settings → Controls → Screenshot: bind it to the same key you told the wizard. They have to match — the app just watches for the file Tarkov creates when you press that key.

Playing with friends (squad mode)

  1. Get the join code from Josia in Discord.
  2. In the game, press F8 to open interact mode.
  3. Open the squad section, type a display name, and enter the code under join.

Your own position only goes to your squad's room — nothing is public, nothing is logged, and a teammate's dot disappears rather than going stale the moment they disconnect.

Troubleshooting

A key does nothing (F8, F6, etc.)

Something else on your PC grabbed that key globally — Discord, GeForce Experience, the Steam overlay and other overlay tools all do this. The app will tell you: a red banner appears top-left naming the key and what it broke. Fix it from the tray icon's Setup wizard → Your keys step, which marks the conflicting key TAKEN — either close whatever owns it, or pick a different key right there.

My dot on the map isn't moving

Press your screenshot key in-game (not necessarily F10 — whatever you set in the wizard) and confirm Escape from Tarkov's screen mode is set to Borderless, not Fullscreen. The dot updates on every screenshot you take, nothing else.
